LiteKai — AR Credit & Accounts Receivable Management System

Live Demo: [litekkel4.vercel.app](https://litekkel4.vercel.app)

About the Project
LiteKai is a bilingual web application built to simplify credit tracking and Accounts Receivable (AR) management. Designed to replace error-prone manual ledgers and scattered spreadsheets, it helps users monitor customer balances, calculate payment schedules, and generate clean documentation in one place.

Background
This project originated as a university coursework assignment focused on building practical, real-world web solutions for everyday business operations. Developed using **Google Antigravity**, LiteKai was created to address the common challenges small businesses face when managing installment-based customer credit, tracking upcoming due dates, and issuing formal payment receipts.

Key Features
* Bilingual Interface: Supports seamless switching between Indonesian and English for accessible daily use.
* AR & Credit Tracking: Monitor active customer accounts, total receivables, and remaining balances at a glance.
* Automatic Installment Calculation: Automatically breaks down payment terms and schedules to minimize manual calculation errors.
* H-1 Due-Date Reminders: Flags payments due the next day so follow-ups are never missed.
* Printable Receipts (*Kwitansi*): Generates clean, print-ready payment receipts directly from the browser.

Tech Stack
* Language: TypeScript
* Build Tool: Vite
* Styling: Tailwind CSS & PostCSS
* Deployment: Vercel

Getting Started

To run this project locally:
1. Clone the repository
   git clone [https://github.com/Elfword/litekkel4.git](https://github.com/Elfword/litekkel4.git)
   cd litekkel4
2. npm install
3. npm run dev
